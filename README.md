📌 Project Summary

This project presents an interactive Vrinda Store Sales Dashboard built using Microsoft Excel to analyze sales performance and customer behavior. The dashboard transforms raw sales data into meaningful business insights through data cleaning, Pivot Tables, Pivot Charts, and Slicers.

The analysis covers monthly sales and order trends, order status, gender-wise sales, age group distribution, top-performing states, and sales channel performance. Interactive filters for Category, Channel, and Month allow dynamic exploration of the data.

The dashboard helps identify key business trends, understand customer demographics, evaluate regional and marketplace performance, and supports data-driven decision-making for improving sales and operational efficiency.
